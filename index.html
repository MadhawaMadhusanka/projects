Oyage Photos Danna Saha GitHub Host Karana Widiya

1. Oyage Project Photos Danna Widiya:

Project folder eka athule images kiyala folder ekak hadala oyage project photos ekata danna (e.g. images/delta-robot.jpg). Ita passe me index.html file eke pahala script eke thiyena projectsData list eke image: "images/delta-robot.jpg" widiyata wenas karanna.

2. Aluth Project Ekak Ekathu Karana Widiya:

Me code eke pahala <script> tag eka athule const projectsData = [...] kiyala array ekak thiyenawa. Eke thiyena project block ekak copy-paste karala aluth project ekak lesiyenma danna puluwan.

3. GitHub Pages Wala Free Host Karana Widiya:

  1. GitHub eke username.github.io kiyala Public repository ekak hadanna.
  2. Me file eka index.html namin saha oyage images folder eka e repository ekata upload karanna.
  3. Repository eke Settings → Pages walata gihin Branch eka main deela Save karanna.
  4. Winadi deken oyage portfolio website eka free live wada karanawa!
